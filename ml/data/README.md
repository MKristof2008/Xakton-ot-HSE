# Данные «Свидетель»

Каталог `ml/data` — это данные для прогонов и демо. Код, который их читает,
живёт в `ml/lakmus/` (demo-режим, датасет) и `ml/tools/` (оценка).

## Файлы

| Путь | Что внутри |
| --- | --- |
| `demo_listings.json` | Шесть готовых лотов для демо ленты и экрана редакции. Формат — `Listing` из `docs/CONTRACT.md` |
| `archive/manifest.json` | Манифест архива уже опубликованных материалов: по нему работает дедупликация и оценка редкости. Пока пустой (`{"items": []}`) |
| `demo/` | Предрасчитанные `CheckResult` для demo-режима фронтенда, файл на проверку |
| `labels_example.jsonl` | Пример разметки для оценки качества (формат, а не рабочий набор) |
| `results_example.jsonl` | Пример результатов прогона, чтобы `ml/tools/eval.py` запускался без модели |

## `demo_listings.json`

Файл — объект с полями `generated_for`, `schema` и массивом `items`.
Каждый элемент — ровно `Listing` из контракта, без лишних полей:

```
id, offer_id, check_id, title, price_rub, currency, state,
created_at, expires_at, trust{score, uncertainty, coverage, level, conflict},
facts{origin, shot_at, geo, unique, similar_in_archive},
why_price[], preview_url
```

Что важно знать, если правишь файл:

- **Цены посчитаны по формуле из контракта**, а не выставлены на глаз:
  `1500 × freshness × uniqueness × provenance × demand`, округление до 100.
  Например, дым над заводом: 1500 × 2.0 (снято 1.5 ч назад) × 2.0 (нет
  совпадений) × 1.5 (метаданные целы, гео совпадает) × 1.8 (ЧП) = 10800 ₽.
  Меняешь цену — пересчитай и поправь `why_price`, иначе демо начнёт врать.
- **`why_price` пишется человеческим языком.** Не «множитель свежести 2.0»,
  а «снято полтора часа назад, дым ещё идёт». Каждый пункт объясняет одну
  цифру в цене. Покупатель должен понять цену без калькулятора.
- **Уровни доверия разные намеренно**: два `confirmed`, два `likely_real`,
  один `fog`, один `doubtful`. Демо должно показывать, что система умеет
  сомневаться, а не ставит всем 90 из 100.
- **Даты — вокруг 13 ноября 2026**, время в UTC (`Z`). `expires_at` — ровно
  семь суток после `created_at`, как `LISTING_TTL_DAYS` в `backend/store.py`.
- **Состояния**: пять лотов `available`, один `sold` — чтобы на экране было
  видно и ленту, и закрытую сделку.

Предпросмотров (`preview_url`) в файле нет: `null`. Реальные картинки в
репозиторий не кладём, демо-интерфейс показывает заглушку по типу материала.

## `archive/manifest.json`

Манифест архива описывает материалы, которые система уже видела: по ним
считается `similar_in_archive` и решается, дубликат перед нами или
оригинал. Формат элемента:

```json
{
  "id": "arc_0a91",
  "sha256": "…",
  "phash": "…",
  "shot_at": "2026-11-10T18:20:00Z",
  "geo": "Москва, Мячковский бульвар",
  "source": "mash",
  "first_seen": "2026-11-10T19:05:00Z"
}
```

Сейчас манифест пуст. Это честное состояние: дедупликация на демо работает
по файлам, загруженным в текущей сессии, а исторического архива у нас нет.
Как только появится наполнение, `similar_in_archive` в лотах начнёт
считаться по этому файлу, а не по нулю.
