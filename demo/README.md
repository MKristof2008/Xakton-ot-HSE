# Демо — что запускать и в каком порядке

Короткая шпаргалка на защиту. Подробный сценарий речи — `docs/PITCH.md`.

## За пять минут до выхода

1. **Фронтенд в демо-режиме**

   ```bash
   cd frontend
   npm run dev
   ```

   `VITE_API_MODE` по умолчанию `demo` — сеть не нужна. Открыть
   `http://localhost:5173` и один раз пролистать ленту, чтобы прогреть сборку.

2. **Backend, если показываем живой прогон**

   ```bash
   cd backend
   ../.venv/Scripts/python.exe -m uvicorn main:app --reload --port 8000
   ```

   Проверить, что порт 8000 свободен: `curl http://localhost:8000/docs` должен
   ответить. Если порт занят чем-то другим — перезапустить, а не менять
   настройки на ходу.

3. **Резервный ноутбук.** Локальная сборка фронтенда (`npm run build` и
   `npm run preview`), без зависимости от сети и от backend. Показывать с
   него, если основное демо упало.

4. **Масштаб экрана 125 %.** На проекторе мелкий текст не читается.

## Что показываем

Порядок и тайминг — в `docs/PITCH.md`. Ключевое:

- лот `lst_2c81` — дым над заводом, цена 10 800 ₽;
- лот `lst_7a19` — остановка, уровень `fog`: показываем сомнение системы
  сами, не ждём вопроса;
- покупка лота от имени Mash — комиссия 20 %, выплата автору.

Данные лотов — `ml/data/demo_listings.json`. Если правите цены, пересчитайте
их по формуле из `docs/CONTRACT.md` и поправьте `why_price`, иначе на защите
будет расхождение между ценой и объяснением.

## Если что-то сломалось

- **Демо зависло** — не перезагружаем страницу в тишине. Говорим вслух, что
  показываем резервную сборку, и переключаемся на второй ноутбук.
- **Backend не поднимается** — показываем фронтенд в демо-режиме. Данные те
  же, отличие только в том, что проверка проигрывается из
  `ml/data/demo/`, а не считается на месте. Об этом говорим прямо.
- **Вопрос про цифры рынка** — отвечаем, что оценок у нас нет, и
  возвращаемся к метрикам пилота из `docs/METRICS.md`.

## Чего не делаем

- Не правим код перед выходом.
- Не подставляем в демо случайные или «красивые» данные.
- Не показываем лот, у которого цена не сходится с `why_price`.
- Не говорим «это работает» про то, что помечено в `README.md` как
  неработающее.
