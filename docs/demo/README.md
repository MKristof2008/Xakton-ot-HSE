# Демо продукта

Записано автоматически: браузер под управлением Playwright прошёл все
четыре сценария на тарифе «Макс», поэтому в кадре виден полный разбор.

## Видео

`demo-walkthrough.webm` — сквозной проход: текст → ссылка → фото → видео.

## Как воспроизвести

```bash
# сервер
python -m uvicorn backend.main:app --port 8000

# интерфейс
cd frontend && npm run dev

# запись демо: четыре сценария, видео и скриншоты в docs/demo
node frontend/record_demo.mjs
```

Скрипт сам создаёт аккаунт, поднимает тариф до «Макса», прогоняет текст,
ссылку, фото и видео, сохраняет кадры и запись экрана.

## Что в кадре не показано

- **Поиск в интернете** — нужен ключ (`SERPER_API_KEY`). Без него страница
  скачивается, но внешний поиск не работает.
- **OCR текста со скриншота** — нужен `pytesseract` или PaddleOCR.
  Без них сигнал честно отвечает «нет данных».
- **Анализ звука и речи в видео** — не подключён.
