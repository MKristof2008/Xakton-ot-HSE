# Демо продукта

Записано автоматически: браузер под управлением Playwright прошёл все
сценарии на тарифе «Макс», поэтому в кадре виден полный разбор.

## Видео

`demo-walkthrough.webm` — сквозной проход по продукту, три разных материала
подряд: фото, видео, ссылка с текстом.

## Кадры по сценариям

| Файл | Что видно |
|---|---|
| `01-home.png` | Главная: вкладки проверки, ссылка, примеры |
| `02-photo-upload.png` | Загрузка скриншота |
| `03-photo-verdict.png` | Вердикт по фото и разбор сигналов |
| `04-video-upload.png` | Загрузка ролика |
| `05-video-verdict.png` | **Видео: «Скорее фейк», в метаданных следы генератора Sora, вес сигнала 85%** |
| `06-link-input.png` | Ссылка на первоисточник плюс текст сообщения |
| `07-link-verdict.png` | Вердикт по тексту с рубрикой и готовой фразой для пересылки |

## Как воспроизвести

```bash
# сервер
python -m uvicorn backend.main:app --port 8000

# интерфейс
cd frontend && npm run dev

# запись демо: три сценария, видео и скриншоты в docs/demo
node frontend/record_demo.mjs
```

Скрипт сам создаёт аккаунт, поднимает тариф до «Макса», прогоняет фото,
видео и ссылку, сохраняет кадры и запись экрана.

## Что в кадре не показано

- **Проверка ссылки в интернете** — нужен ключ поиска (`SERPER_API_KEY`).
  Без него страница скачивается, но внешний поиск не работает.
- **OCR текста со скриншота** — нужен `pytesseract` или PaddleOCR.
  Без них сигнал честно отвечает «нет данных».
- **Анализ звука и речи в видео** — не подключён.
