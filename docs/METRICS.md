# Метрики качества — на чём проверено

Все цифры получены на реальных прогонах этого репозитория.
Ничего не оценено «на глаз»: каждая строка воспроизводится командой ниже.

## Текст и ссылки

Набор: `ml/data/eval_set.json` — 28 кейсов, размеченных по классам.

```bash
python -I ml/tools/eval_run.py --with-llm      # с ключами LLM и поиска
python -I ml/tools/eval_run.py                 # без сети, только база фактов
```

| Класс кейсов | Результат | Что проверяет |
|---|---|---|
| Факты из базы | **7/7** | «ставка 21%», «МРОТ 22 440», «пенсионный возраст 65» |
| Опровержение базой | **5/5** | «ЦБ запретил наличные», «штраф за алкоголь 5000» |
| Отрицания | **2/2** | «ЦБ не запрещал наличные» — правда, не фейк |
| Реальные новости | **2/2** | «мост в Казани», «воду на Марсе нашли» |
| Выдумки с покрытой темой | **5/5** | «комендантский час», «роспуск Госдумы», «налог на наличные» |
| Прогнозы | **2/3** | «завтра снег» — непонятно, а не фейк |
| Вне базы | **1/2** | «компания X купила Y» — непроверяемо |
| **Итого** | **26/28 (93%)** | |

Время: медиана **3 мс** (ответ из базы фактов), максимум **41 сек**
(полный путь: поиск в интернете + модель).

### Где проваливается и почему

- **«Мобилизацию объявят со следующей недели»** → «фейк» вместо «непонятно».
  Строгий режим сработал раньше проверки на прогноз.
- **«Вчера в Казани открыли новый мост»** → «правда» вместо «непонятно».
  Мост реально открывали, но не вчера — система не сверяет дату.

Оба провала — на границе «слух против факта». Честнее было бы «непонятно»,
но строгий режим (по просьбе заказчика) трактует отсутствие подтверждения
как фейк.

## Фото

Проверено на четырёх реальных файлах: два сгенерированных и два настоящих.

| Файл | Что это | Вердикт системы | Верно |
|---|---|---|---|
| портрет с веснушками | генерация | фейк, 13/100 | ✅ |
| коллаж «девушка + тоннель» | генерация | фейк, 13/100 | ✅ |
| фото на пляже | настоящее | правда, 83/100 | ✅ |
| селфи в магазине | настоящее | правда, 83/100 | ✅ |
| **Итого** | | | **4/4** |

Модель: `Ateeqq/ai-vs-human-image-detector`, уверенность 0.999–1.000
на всех четырёх. Время: **0.2 сек** на фото после загрузки модели.

**Честное ограничение:** четыре файла — не выборка. Модель обучена на
фотореалистичных генерациях; на стилизованных картинках, рисунках и
скриншотах её вывод не проверялся.

## Видео

Проверено на двух сгенерированных роликах:

| Ролик | Ожидание | Результат |
|---|---|---|
| 30 кадров, движущийся объект | не фейк | нейтрально, «следов генератора нет» ✅ |
| 30 одинаковых кадров | фейк (фото как видео) | supports_fake, «кадры почти не отличаются» ✅ |

**Чего система не делает:** не распознаёт речь, не анализирует звук, не
смотрит содержимое кадров. Только метаданные контейнера, подписи
генераторов (Sora, Runway, Pika, Kling, Veo) и проверку статичности.

## Дубликаты фото

Перцептивный хеш dHash + aHash, сверка с архивом:

- оригинал в архиве → «дубликат», 0 ₽, лот не создаётся ✅
- та же картинка, пересохранённая в JPEG q55 → «дубликат» ✅
- другой кадр → «совпадений нет» ✅

## Что этим метрикам можно и нельзя доверять

**Можно:** «система правильно отвечает на известные факты», «отличает
сгенерированное фото от снятого на камеру», «ловит дубликаты и
пересохранённые копии», «на прогноз не говорит фейк».

**Нельзя:** «система верна в 93% случаев на любых новостях». Набор из 28
кейсов составлен нами, а не независимой выборкой. На незнакомых темах
система честно отвечает «непонятно» — и это правильное поведение, а не
провал.

## Воспроизвести

```bash
# текст: нужен .env с LLM_API_KEY и SERPER_API_KEY
python -I ml/tools/eval_run.py --with-llm --json

# без ключей — только база фактов, быстро и офлайн
python -I ml/tools/eval_run.py
```

Отчёт сохраняется в `ml/data/eval_report.json`: по каждому кейсу вердикт,
пояснение, время и статус.
